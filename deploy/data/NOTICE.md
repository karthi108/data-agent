# Bundled demo database

`student_club.sqlite` is the `student_club` database from the BIRD benchmark (Mini-Dev
package), copied unchanged so the live demo can run without downloading the full 800 MB
benchmark. Its sha256 matches `eval/data_manifest.json`, which `tests/test_deploy.py` checks.

- Source: BIRD, "Can LLM Already Serve as a Database Interface? A BIg Bench for Large-Scale
  Database Grounded Text-to-SQLs" (Li et al., NeurIPS 2023), https://bird-bench.github.io/
