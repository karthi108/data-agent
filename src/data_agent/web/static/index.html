Data Agent

Ask a question about the database in plain language. The agent explores the schema, runs read-only SQL, fixes its own errors, asks when a question is ambiguous, and every number in its answer must come from a query it ran.

Demo mode: answers are scripted for the example questions (no AI calls). The real agent, tools, database and checks still run.
Read-only access (SELECT only, read-only connection), 5 s per query, max 8 steps and $0.05 per question, daily budget cap. Data: BIRD benchmark (CC BY-SA 4.0).
